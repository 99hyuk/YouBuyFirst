# Front TossInvest Dark Theme Design

## 결정 요약

너나사 front 대시보드는 `다크 모드 기본값 + 라이트 모드 지원`으로 디자인을 보강한다.

기준 레퍼런스는 토스증권이다. 토스증권에서 가져올 것은 브랜드 복제가 아니라 쉬운 주식 탐색 경험의 구조다. 즉 검색 진입, 홈/피드/종목 탐색 성격의 내비게이션, 실시간 차트와 랭킹 필터, 투자 유의사항을 화면 안에 자연스럽게 두는 방식이다.

YASUN.GG에서는 시장감 있는 다크 터미널과 랭킹 밀도를 참고한다. SimplyStock에서는 진단 카드, 데이터 분석 도구 톤, 투자 참고용 고지의 위치를 참고한다.

너나사는 실거래 앱이 아니므로 매수, 매도, 추천, 수익 보장처럼 읽히는 표현은 쓰지 않는다. 화면의 핵심 문장은 `커뮤니티 반응을 관찰하는 참고 서비스`에 맞춘다.

## 목표

- 기본 테마를 다크 모드로 바꿔 전문적이고 시장감 있는 첫인상을 만든다.
- 라이트 모드는 같은 정보 구조를 밝은 배경에서 볼 수 있는 보조 테마로 제공한다.
- TossInvest처럼 사용자가 바로 검색, 필터, 랭킹, 주요 섹션을 이해하게 한다.
- YASUN처럼 `지금 뜨는 반응`, 기간 탭, 랭킹 밀도를 일부 가져온다.
- SimplyStock처럼 분석 결과가 투자 권유가 아니라 참고 데이터임을 명확히 표시한다.
- 기존 fixture/mock 기반 화면 계약과 `기획자 확인 필요` 경계를 유지한다.

## 비목표

- 토스증권, Toss, YASUN, SimplyStock의 브랜드, 로고, 고유 UI를 복제하지 않는다.
- 실제 API 연동, 실제 시세, 실제 수익률 산식, 차트 라이브러리 확정은 하지 않는다.
- 실거래, 주문, 로그인, 계좌, 개인화 투자 추천 플로우를 추가하지 않는다.
- 고충실도 브랜드 디자인 시스템 전체를 확정하지 않는다.

## 참고 사이트에서 가져올 정보 구조

참고 링크:

- 토스증권: https://www.tossinvest.com/
- SimplyStock: https://www.simplystock.co.kr/
- YASUN.GG: https://yasun.gg/

### 토스증권

토스증권은 홈, 피드, 주식 골라보기, 내 계좌 같은 쉬운 탐색 항목과 검색 진입을 전면에 둔다. 화면에는 실시간 차트, 지금 뜨는 카테고리, 국내 투자자 동향, 거래대금, 거래량, 급상승, 급하락 같은 시장 탐색 축이 있다. 또한 투자위험 주식 숨기기와 투자 유의사항 같은 보호 장치를 둔다.

너나사 적용:

- 상단 또는 좌측에 `홈`, `피드`, `종목 골라보기`, `커뮤니티`, `에이전트` 성격의 내비게이션을 둔다.
- 검색 또는 검색형 입력 표면을 둔다. 실제 검색 기능이 없으면 `mock search` 또는 disabled 상태로 명확히 표시한다.
- `지금 뜨는 반응`, `종목별 심리 비교`, `커뮤니티 수익률 비교`처럼 필터와 랭킹이 있는 정보 블록을 둔다.
- 투자 유의사항은 하단으로만 밀지 말고 대시보드 안의 보조 카드나 배지로 노출한다.

### YASUN.GG

YASUN은 지금 시장, 실시간 차트, 속보 뉴스, 롱숏 채팅, 매매동향, 예측, 실시간 종목 랭킹처럼 트레이더가 빠르게 훑는 정보를 앞에 둔다. 다크 터미널 성격이 강하고 정보 밀도가 높다.

너나사 적용:

- 전체를 과한 터미널로 만들지 않고, 다크 기본 테마에서 `지금 뜨는 반응` 패널만 밀도 있게 둔다.
- 필터 칩, 기간 탭, 랭킹 리스트, 상승/하락 색상으로 시장감을 만든다.
- `실시간`이라는 표현은 실제 실시간이 아닐 때 쓰지 않는다. 대신 `최근 1시간`, `mock`, `stale quote`, `실시간 아님` 같은 상태를 명확히 표시한다.

### SimplyStock

SimplyStock은 포트폴리오 건강검진, 밸류에이션 미리보기, 수급 반전 신호처럼 진단형 카드와 행동 링크를 노출한다. 동시에 투자 참고용 데이터 분석 도구이며 매수, 매도를 권유하지 않는다는 고지를 둔다.

너나사 적용:

- 진단형 카드 구조를 `커뮤니티 반응 브리핑`, `종목별 심리 비교`, `기획자 확인 필요`에 적용한다.
- CTA는 `내 종목 분석하기`보다 `반응 자세히 보기`, `커뮤니티 비교 보기`처럼 관찰형으로 둔다.
- 고지는 `투자 자문이 아니라 커뮤니티 반응을 관찰하는 참고 화면입니다.`를 기본 문장으로 유지한다.

## 화면 구조

### App Shell

기본 구조는 데스크톱에서 좌측 내비게이션 + 메인 대시보드로 바꾼다. 모바일에서는 상단 브랜드와 가로 스크롤 또는 줄바꿈 내비게이션으로 축약한다.

- 좌측 또는 상단 브랜드: `너나사 YouBuyFirst`
- 보조 문장: `커뮤니티 반응으로 먼저 흔들리는 지점을 관찰합니다.`
- 주요 링크: `홈`, `종목 상세`, `커뮤니티`, `에이전트`, `포트폴리오 준비 중`
- 검색 표면: `/ 를 눌러 종목이나 키워드를 검색하세요`
- 테마 토글: `다크`, `라이트`

테마 토글은 이 PR에서 실제 상태 전환까지 구현한다. 저장은 `localStorage`를 사용한다. 저장값이 없으면 다크 모드가 기본값이다.

### Dashboard

대시보드는 다음 순서로 구성한다.

1. 상단 검색/상태 바
2. 커뮤니티 브리핑 히어로
3. 지금 뜨는 반응 랭킹
4. 종목별 심리 비교
5. 커뮤니티 수익률 비교
6. 가격 상태 placeholder
7. 기획자 확인 필요와 투자 참고 고지

첫 화면은 히어로만 크게 만들지 않는다. 토스증권처럼 바로 탐색 가능한 정보 표면을 보여주기 위해 히어로와 랭킹 패널을 같은 viewport 안에 둔다.

## 컴포넌트 방향

### Search Surface

검색 표면은 실제 기능이 없는 동안 버튼처럼 보이되, disabled 또는 mock 상태를 명확히 둔다.

문구:

- `/ 를 눌러 종목이나 키워드를 검색하세요`
- 보조 배지: `mock search`

### Market Reaction Panel

YASUN식 시장감을 담당하는 다크 패널이다. 라이트 모드에서도 이 패널은 약간 진한 표면을 유지해 핵심 랭킹 역할을 한다.

포함 정보:

- `지금 뜨는 반응`
- 기간: `최근 1시간`
- 필터 칩: `전체`, `언급 증가`, `심리 변화`, `가격 stale`
- 랭킹 행: 순위, 종목명, 심볼, 언급 증가율, 상태 배지

### Stock Mood Cards

기존 `종목별 심리 비교` 카드를 더 Toss식으로 정돈한다.

포함 정보:

- 종목명, 심볼, 시장
- 열기 지수 원형 또는 숫자 배지
- 언급 수와 전시간 대비 증가율
- 반응 방향 막대
- 핵심 키워드 2-3개
- `mock quote` 또는 `stale quote`

### Return Comparison

`커뮤니티 수익률 비교`는 강한 투자 성과처럼 보이지 않게 `mock paper return` 또는 `모의 성과 비교` 문구를 함께 둔다.

포함 정보:

- 기간 탭: `1D`, `7D`, `1M`, `3M`, `6M`
- 커뮤니티별 라인 차트 mock
- 고지: `실제 수익률이 아니라 커뮤니티별 모의 성과 화면 계약을 보기 위한 fixture입니다.`

### Planning Boundary

기획자 확인 필요 섹션은 숨기지 않는다. MVP 단계에서는 화면 계약의 일부로 유지한다.

포함 항목:

- 열기 지수 산식과 명칭
- 종목별 심리 비교의 반응 막대 산식
- 커뮤니티 수익률 비교 산식과 기간
- AI 요약 placeholder 문구

## 테마 시스템

테마는 CSS custom properties로 구현한다. `html` 또는 app root에 `data-theme="dark"` / `data-theme="light"`를 둔다.

### Dark 기본값

목표: 전문적, 시장감 있음, 너무 무겁지 않음.

권장 토큰:

- `--bg`: `#0f1117`
- `--surface`: `#171a22`
- `--surface-raised`: `#1f2430`
- `--border`: `#2d3442`
- `--text`: `#f2f4f6`
- `--muted`: `#a6b0bf`
- `--subtle`: `#6b7684`
- `--accent`: `#3182f6`
- `--accent-soft`: `#1d3558`
- `--positive`: `#16c784`
- `--negative`: `#ff6b6b`
- `--warning`: `#f59f00`

### Light 지원

목표: Toss식 밝고 쉬운 금융 앱 느낌.

권장 토큰:

- `--bg`: `#f6f8fb`
- `--surface`: `#ffffff`
- `--surface-raised`: `#f9fafc`
- `--border`: `#e6ebf2`
- `--text`: `#191f28`
- `--muted`: `#4e5968`
- `--subtle`: `#8b95a1`
- `--accent`: `#3182f6`
- `--accent-soft`: `#eef6ff`
- `--positive`: `#00a86b`
- `--negative`: `#f04452`
- `--warning`: `#f59f00`

색상 원칙:

- 블루는 행동과 주요 강조에만 사용한다.
- 상승/하락 색은 보조 정보에만 사용하고, 투자 판단처럼 보이는 과장 색면을 피한다.
- 보라/남색 그라디언트, 베이지/브라운 계열, 과한 단색 테마는 쓰지 않는다.
- 카드 중첩은 피하고, 페이지 섹션은 full-width band 또는 단일 표면으로 정리한다.

## 접근성과 반응형

- 테마 토글은 버튼으로 만들고 현재 상태를 텍스트와 `aria-pressed`로 드러낸다.
- 탭처럼 보이는 기간 선택은 실제로 동작하지 않으면 button을 쓰되 mock 상태를 문구로 표시한다.
- 모바일 390px에서 내비게이션, 검색 표면, 랭킹 카드 텍스트가 겹치지 않아야 한다.
- 카드, 버튼, 토글은 최소 높이 36px 이상을 유지한다.
- 숫자와 종목명은 줄바꿈 시 정보가 끊기지 않게 `min-width: 0`, `word-break: keep-all`, `overflow-wrap`를 조정한다.

## 구현 범위

수정 대상:

- `front/src/App.vue`
- `front/src/pages/DashboardPage.vue`
- `front/src/styles.css`
- 필요 시 `front/src/fixtures/dashboard-summary.json`
- `front/src/__tests__/shell.spec.ts`

추가 가능:

- `front/src/composables/useTheme.ts`

테스트:

- 기본 렌더링 시 다크 모드 상태가 존재한다.
- 테마 토글 버튼이 렌더링된다.
- TossInvest형 검색 표면과 `지금 뜨는 반응` 패널이 렌더링된다.
- 투자 권유가 아닌 참고 화면 고지가 유지된다.
- 기존 `종목별 심리 비교`, `커뮤니티 수익률 비교`, `기획자 확인 필요` 문구가 유지된다.

검증:

- `npm.cmd test`
- `npm.cmd run build`
- `git diff --check origin/main...HEAD`
- 브라우저 QA: `http://127.0.0.1:5174/dashboard`
- 브라우저 QA 항목: 다크 기본값, 라이트 전환, 데스크톱 첫 화면, 모바일 390px 겹침 없음, 콘솔 에러 0개

## 리스크

- 토스증권을 너무 직접적으로 모사하면 브랜드 복제처럼 보일 수 있다. 구조와 원칙만 참고한다.
- 다크 기본값은 전문적으로 보이지만 과하면 실거래 터미널처럼 보인다. 고지, mock 배지, 관찰형 문구로 균형을 잡는다.
- 수익률 비교는 투자 성과처럼 보일 수 있다. `mock`, `모의 성과`, `fixture` 문구를 함께 둔다.
- 라이트/다크를 한 번에 추가하면 CSS가 커질 수 있다. CSS 변수와 기존 클래스 재사용으로 범위를 좁힌다.

## 승인된 방향

사용자가 승인한 방향은 `다크 기본 + 라이트 지원`이다. 구현은 이 spec을 기준으로 진행한다.
